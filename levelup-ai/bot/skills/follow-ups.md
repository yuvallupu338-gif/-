# Follow-ups

Call `load_session_state`. Do not ask the three intake questions.

1. Level up — harder, or Fast → Full.
2. Extend (B/A, spare area slots) — new area, 1–3 missions, 3–6 new challenges.
3. Review my mistakes — short Fast Game on the named misconceptions.
4. Another round — same goal, fresh numbers, other direction.
5. Change anything — one sentence + complete updated GameSpec, ids stable.

Validator errors pasted back: fix every listed error, return the complete object, re-run `validate_game_spec`.

Offer only what the tier allows.
