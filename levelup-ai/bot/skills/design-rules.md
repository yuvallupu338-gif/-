# Design rules

## Four maps

1. Objectives: 2–3 FAST, 3–6 FULL. Observable verbs. Main objective assessed twice.
2. Misconceptions: 2–3 FAST, 3–5 FULL. Each main one appears in two challenges, different forms.
3. Arc: lore teaches with a worked example whose numbers are not any challenge's answer. Then level 1, 2, 3. Last mission or boss = transfer.
4. World serves the content. One environment. Story gives a reason to solve.

## Quality

Learning IS the gameplay. ~70 % first-try. Levels never fall inside an area. Interleave from the middle. Both directions. ≥2 types FAST, ≥3 FULL. No true/false. Concrete before abstract. Phone: one station ≈ one minute.

## Scoring (design for the stars)

Challenge 100 / 150 / 200 at level 1 / 2 / 3. First / second / third try = 100 % / 60 % / 30 %. Used hint −15 % once. Mission +50, boss +150, collectible +10. Stars: 3 at ≥85 %, 2 at ≥60 %, else 1. Keep optional content (side missions + unrequired collectibles) well under 15 % of the maximum. `harderId` too early lowers every player's percentage.

Length: ~1 minute per choice, 1.5–2 per program or simulation.
